# Карты на реальной географии

`australia.json`, `brazil.json`, `japan.json` в `src/assets/maps/data/` — не
процедурная генерация (в отличие от `small_*`/`medium_*`/`large_*`), а
настоящие административные границы стран: провинции — это реальные штаты
Австралии, штаты Бразилии, префектуры Японии.

## Источник данных

[Natural Earth](https://www.naturalearthdata.com/) 5.1.1, admin-1 (states/
provinces), public domain — не требует ни разрешения, ни атрибуции (хотя
Natural Earth будет благодарен за упоминание).

Данные взяты не напрямую с сайта Natural Earth, а через npm-пакет
[`apexmaps-geo`](https://www.npmjs.com/package/apexmaps-geo) — он уже
поставляет их в TopoJSON (с общей топологией между соседними провинциями,
это важно для `build-real-maps.js`, см. ниже) и с чёткой лицензией
(`CC0-1.0 AND CC-BY-4.0` на пакет, `LICENSE` внутри пакета — public domain на
сами данные Natural Earth).

## Как перегенерировать

Сырые TopoJSON-паки (`apexmaps-geo`) в репозиторий не кладём — они
устанавливаются как обычная npm-зависимость во временную папку:

```
mkdir -p /tmp/geo-build && cd /tmp/geo-build
npm init -y
npm install apexmaps-geo topojson-client topojson-simplify
node /path/to/maps-source/geo-source/build-real-maps.js
```

`build-real-maps.js` ожидает `apexmaps-geo` в `node_modules` рядом с собой
(через `require`) и пишет готовые JSON прямо в
`src/assets/maps/data/<name>.json` — путь назначения захардкожен в скрипте
абсолютным путём внутри репозитория.

## Что делает скрипт

1. `topojson-simplify` (presimplify + quantile + simplify) — упрощает
   геометрию, сохраняя общую топологию: у соседних провинций граница остаётся
   ровно одной и той же линией, без зазоров/наползаний, которые возникли бы
   при независимом упрощении каждой провинции по отдельности.
2. `topojson-client.neighbors()` — соседство провинций берётся из общих дуг
   топологии, а не считается геометрически (надёжнее, чем проверка "касаются
   ли полигоны").
3. `topojson-client.merge()` — контур всей страны как объединение всех
   провинций; для архипелагов (Япония, Австралия+Тасмания) в контуре
   остаётся несколько колец — по одному на крупный остров, мелкие острова
   (< 0.3% от общей площади) отбрасываются, чтобы не засорять контур.
4. Проекция: equirectangular со сжатием по `cos(средняя широта)` — простая
   поправка, чтобы страна не выглядела растянутой по долготе; для карт такого
   масштаба (одна страна) этого достаточно, честная картографическая
   проекция не нужна.
5. Провинция = самый крупный полигон её геометрии (если у провинции в
   реальности есть мелкие острова — они отбрасываются, как и в процедурном
   генераторе, где на провинцию всегда один простой полигон).
6. Регионы (для бонуса за полный контроль) — k-means по центроидам
   провинций, тот же принцип, что в `map_generator.py`, но не historically
   точные (реальных административных "регионов из регионов" эти данные не
   содержат).
7. Провинции, чья площадь после проекции меньше 1% самой крупной провинции
   карты, отбрасываются целиком (с переиндексацией id/neighbors) — это
   крохотные удалённые территории вроде Jervis Bay Territory или Macquarie
   Island, которые на масштабе всей страны схлопываются в точку в открытом
   море, а не полноценная провинция для завоевания.

## sizeClass

Штаты/провинции трёх выбранных стран сами легли в уже существующие
`small`/`medium`/`large`-бакеты игры (после фильтрации совсем мелких
территорий, см. выше):

| Страна | Провинций | sizeClass |
|---|---|---|
| Австралия | 7 (из 12 admin1-единиц; отброшены Jervis Bay Territory, Macquarie Island, Lord Howe Island, Ashmore and Cartier Islands, Australian Capital Territory) | small |
| Бразилия | 26 (из 27; отброшен Distrito Federal) | medium (20–28) |
| Япония | 47 | large (38–50) |

Канада (13 провинций, идеально ложилась в `small`) не подошла на практике —
её арктический архипелаг настолько изрезан, что даже при самом агрессивном
упрощении отдельные провинции (Нунавут) оставались на 500+ точек. Австралия
даёт тот же размер карты при вменяемой сложности геометрии.

Отдельная ловушка: для Японии дефолтный уровень упрощения (quantile 0.01)
убивал Окинаву — архипелаг из мелких островов при глобальном упрощении
топологии получал настолько низкий локальный "вес" точек, что схлопывался в
вырожденное пятно нулевой площади, хотя это реальная префектура с населением
~1.4 млн. Пришлось смягчить упрощение до 0.05 именно для Японии — ценой
чуть большей детализации остальных префектур.
