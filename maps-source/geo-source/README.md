# Карты на реальной географии

`world_small.json`, `world_medium.json`, `world_large.json` в
`src/assets/maps/data/` — не одна страна с настоящими административными
границами (так было в первой версии, см. git-историю), а **несколько
соседних стран** с настоящими контурами, каждая поделена на небольшое
управляемое число провинций (3–5) процедурно, не по реальным admin1-границам.

Так ближе к референсу игры (Age of Conquest IV): страна на карте — это
компактная группа из нескольких клеток одного цвета, а сама карта — целый
регион/континент из многих стран, а не один детально расписанный кусок суши.

| Карта | Стран | Провинций | Состав |
|---|---|---|---|
| `world_small` | 3 | 12 | Франция, Испания, Португалия |
| `world_medium` | 6 | 25 | + Италия, Германия, Швейцария |
| `world_large` | 11 | 43 | + Австрия, Бельгия, Нидерланды, Великобритания, Польша |

Каждая страна = один `region` в схеме карты (не k-means-кластер, как в
`map_generator.py`, — тут группировка осмысленная и совпадает с visual
"страной" на карте).

## Источник контуров стран

Natural Earth 5.1.1, страны (admin-0), public domain — через тот же
[`apexmaps-geo`](https://www.npmjs.com/package/apexmaps-geo), что и раньше
(`world-countries-50m.json`).

## Как перегенерировать

Два шага — Node (топология → GeoJSON) и Python (своя Voronoi-нарезка,
как в `map_generator.py`, но внутри настоящего контура страны, а не
случайного "блина"):

```
mkdir -p /tmp/geo-build && cd /tmp/geo-build
npm init -y
npm install apexmaps-geo topojson-client topojson-simplify
node /path/to/maps-source/geo-source/export-countries.js
# -> countries-small.json / countries-medium.json / countries-large.json
# в ТЕКУЩЕЙ директории (build_world_map.py их оттуда же и читает)

pip install numpy scipy shapely
python3 /path/to/maps-source/geo-source/build_world_map.py
# пишет src/assets/maps/data/world_{small,medium,large}.json напрямую
# (путь назначения захардкожен в скрипте)
```

Список стран и число провинций на страну — в начале каждого файла
(`SETS` в `export-countries.js`, `PROVINCES_PER_COUNTRY` в
`build_world_map.py`). Поменять состав карты — значит поменять эти списки.

## Что делает `build_world_map.py`

1. Берёт реальный контур каждой выбранной страны (из GeoJSON, который
   выгрузил `export-countries.js`), отбрасывает совсем мелкие острова
   (< 2% площади самого крупного острова этой же страны).
2. Раскидывает точки внутри страны — пропорционально площади каждого
   острова, минимум одна точка на остров (иначе крупный отдельный остров,
   как Северная Ирландия у Великобритании, рискует остаться без провинции).
3. **Все точки со всех стран объединяются в один Voronoi-диаграм** (та же
   техника, что в `map_generator.py`: `scipy.spatial.Voronoi` +
   Lloyd-релаксация, только `lloyd_relax` тут применяет relax к точке
   индивидуально в границах именно её страны, а не общего "острова") — это
   даёт честное соседство провинций и через границы стран тоже, не только
   внутри одной страны.
4. Каждая Voronoi-ячейка обрезается по контуру своей страны.
5. `boundary` — это все острова всех выбранных стран (несколько колец,
   как и для архипелагов в предыдущей версии).

## Отличие от первой версии (admin1 одной страны)

Первая версия (см. `git log` — коммит "Real-world province maps:
Australia, Brazil, Japan") брала настоящие admin1-провинции одной страны
через `topojson-simplify`/`topojson-client`. От неё отказались: пользователь
хотел не detailed real provinces одной страны, а компактную мульти-страновую
карту с управляемым числом клеток на страну — то, что тут и реализовано.
