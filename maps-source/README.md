# Карты — пак для Territoria

15 сгенерированных карт: 5 маленьких (10–14 провинций), 5 средних (20–28),
5 больших (38–50). Каждая — уникальный "остров/континент" со своей формой
береговой линии, разбитый на провинции алгоритмом Вороного + релаксация
Ллойда (то же семейство техник, которым в стратегиях процедурно генерируют
карты кампании — получаются органичные, а не квадратные/шестиугольные клетки).

## Структура

```
data/<name>.json     — данные для игры: провинции (id, полигон, svgPath,
                        centroid, neighbors), регионы (для бонуса за полный
                        контроль), контур береговой линии
assets/<name>.svg     — тот же полигон в виде готового SVG (нейтральная
                        заливка — цвет владельца проставляется в приложении
                        во время игры)
previews/<name>.png   — цветной превью-рендер (цвет = регион), только для
                        визуальной проверки, в приложение не идёт
index.json             — сводка: список карт, sizeClass, число провинций
map_generator.py       — сам генератор (Python)
```

Это и есть те самые `map.json` / `map.svg`, которые упоминались в структуре
проекта — просто теперь их 15 штук, разложенных по `sizeClass`.

## Формат data/<name>.json

```json
{
  "name": "medium_03",
  "sizeClass": "small|medium|large",
  "viewBox": "0 0 1000 700",
  "provinceCount": 20,
  "boundary": [[x,y], ...],
  "provinces": [
    {
      "id": 0,
      "regionId": 1,
      "points": [[x,y], ...],
      "svgPath": "M ... Z",
      "centroid": [x, y],
      "neighbors": [1, 4, 7]
    }
  ],
  "regions": [
    { "id": 1, "provinceIds": [0,3,5], "controlBonus": 2 }
  ]
}
```

`viewBox` одинаковый у всех карт (`0 0 1000 700`) — можно рендерить любую
карту одним и тем же `MapSvg`-компонентом без пересчёта масштаба.

## Если нужно больше карт или другие параметры

```
python3 map_generator.py
```

Число карт/провинций на класс размера и радиус острова задаются в `main()`
(список `plan`). Каждая карта детерминирована своим `seed` — тот же seed
всегда даёт ту же карту.
